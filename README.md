# Odoo Travel Services

Odoo modules for a travel and tourism services company: service applications with their
sales and purchase orders, running partner balances and statements of account.

The modules rebuild, as clean and tested code, an implementation first built with Odoo Studio
and automations for a travel and tourism services company in the UAE.

## Modules

| Module | Description | Status |
|--------|-------------|--------|
| `travel_application` | Service applications: lines per service, stages, sales and purchase orders | In development |
| `partner_running_balance` | Running partner balances, prepaid accounts and statements of account | Planned |

Install only modules marked **Available**: modules **In development** are incomplete.

## Versions

| Branch | Status |
|--------|--------|
| 18.0 | Active |
| 17.0, 19.0 | Planned |
